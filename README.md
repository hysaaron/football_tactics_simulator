# FIELDLAB · NFL 战术实验室

本地优先、零依赖的 NFL 攻防战术沙盘。借鉴战术选择卡片的操作形式，以圆形和叉号呈现 11 对 11 演化。所有界面为中文，战术保留英文名称方便对照学习。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。支持子路径部署，全部静态资源在 `dist/`，不要通过 `file://` 打开 ES 模块。

## 使用

1. 打开页面默认选中 `Custom Left Cross` 对 `425 C6 W Blitz`，并将两张自定义战术卡放在各自列表首位。32 队均可选择，切换球队仍载入该队示意预设，可以自由切换全部概念。
2. 在攻防标签下选择战术，设置开球位置、首攻距离、接球目标、出手时机和随机种子。
3. 开始、暂停、逐帧、拖动时间轴或改变播放速度；切换路线、防守区域或镜像。
4. 运行 100 次，以连续种子比较平均推进、首攻达成率和传球完成率。改变配置会清空过期统计。

## 模型与数据边界

- 7 个进攻概念、11 个防守概念；不是官方 Madden 或真实赛季球队战术库。所有球队共用同一能力分布，球队不影响能力评分。
- 固定步长 0.05 秒，无单档时间截断；直到传球未完成、持球出界、达阵、擒杀、擒抱或抄截等结束事件才停止。抄截目前直接结束，不模拟回攻。回放时间轴跟随实际回合长度。
- 防守包含区域目标、盯人、简化冲传阻挡与追击。跑球包含预设跑卫路线，未实现完整区域阻挡决策。
- 传球概率由防守分离距离、目标纵深和随机种子决定。无真实 NFL 数据拟合；批量统计不能用于比赛预测。
- 未实现犯规、掉球、真实球员、完整比赛管理或官方规则裁决。
- 球队目录来源：[NFL 官方球队列表](https://www.nfl.com/teams/)。默认概念映射为本项目教学预设，不声称反映当前球队倾向。

## 修改战术

编辑 `dist/data.js`。路线由 `[横向码数, 相对开球线的纵向码数]` 航点组成；横向范围 0–53.3，纵向正数为推进方向。进攻 `starts` 可覆盖 X/H/Y/Z/RB 初始站位，`qbStart` 设置 QB 站位。防守 `assignments` 分别定义每位防守者的起点、盯人对象或区域中心与半径。`engine.js` 为可独立测试的模拟核心；`app.js` 管理状态、SVG 渲染和交互；`style.css` 定义响应式布局。

新增用户手绘变体 `425 C6 W Blitz · W 突袭 · 双深轮转`，以 Even 前线为默认：WLB 沿右侧平滑弧线绕过 C/D 缝外缘后收向 QB；S-R 开球前就站在 `[41,7]` 的右浅区，不再从 18 码深区出发。S-L 和 C-R 分守两个深半场；C-L、EG、SLB 保持浅区职责。共五人冲传、四浅区、两深区。原 Cover 6 Left 保留。该变体来自用户标注，不是 PDF 原有战术。突袭在 `assignments` 中用 `mode: 'blitz'`、三次贝塞尔控制点 `curve` 和终点 `target` 定义：起点 `[31,5]`，控制点 `[40,4]`、`[40,-5]`，终点 `[32,-6]`，随后追击 QB。战术卡、球场示意与实际跑动共用 `assignmentPath`，移动按距离预算通过曲线采样点，镜像时完整翻转；阻挡逻辑包含参与突袭的线卫，人数保持 11 对 11。

覆盖区域和前线距离也是图示近似；仍使用简化阻挡、区域交接与概率接球，不是完整教练规则系统。

### 独立模拟配置

`dist/config.js` 是参数的唯一默认值来源，页面和引擎共同读取。`DEFAULT_MATCHUP` 指定页面初始选中的自定义攻防组合。修改 `parameterDefinitions` 中对应参数的 `default` 后刷新页面即可。页面右侧的“模拟参数”提供临时调节和恢复默认按钮；调节会重算回放、清空旧批量统计，单次与 100 次推演使用相同参数。页面调节不会写回文件，刷新恢复文件默认值。

| 参数 | 默认值 | 可调范围 | 含义 |
| --- | --- | --- | --- |
| `releaseTime` | 2.8 秒 | 0.8–4.5 秒 | QB 出手前等待时间；切换进攻战术时会载入该战术的建议值 |
| `passDepthWeight` | 0.20 | 0–2 | 自动选目标的纵深权重；评分 = 分离距离 + 权重 × min(纵深, 首攻距离)；不影响手动指定目标 |
| `catchAbility` | 1 | 0–2 倍 | 原模型实际接球成功概率的倍率，0 无法接住、1 基准、2 两倍；抄截概率保持原规则 |
| `breakTackleChance` | 0.15 | 0–1 | 接球／跑球持球者每次接触防守者时挣脱的概率，不适用于 QB 擒杀 |
| `shedBlockChance` | 0.25 | 0–1 | 冲传者与每名阻挡者每次接触时摆脱的概率 |

接球实际概率 = `clamp((原接球阈值 − 抄截概率) × catchAbility, 0, 1 − 抄截概率)`；1 倍保留原接球公式。能力参数目前统一作用于全部相应角色，不区分球队、球员评分。

摆脱阻挡按每一对冲传者／阻挡者判定一次，持续接触期间复用结果；两人分离超过 3 码后可重新判定。成功只解除该阻挡者的减速，其他阻挡者仍可阻挡。挣脱擒抱成功后，该防守者停顿 0.6 秒，分离超过 1.5 码后才能再次形成擒抱接触；其他防守者仍可立即擒抱。不会在每个 0.05 秒步长重复抽签。相关距离与恢复时间也集中在配置文件的 `contactRules`。

引擎可通过 `simulate({ parameters: { passDepthWeight: 0.3, catchAbility: 1.2, breakTackleChance: 0.2, shedBlockChance: 0.4 } })` 覆盖默认值。缺省／无效值回退到默认值，数值越界会被限制到范围内。结果的 `config.parameters` 返回实际使用的配置，方便复现。

```sh
npm test
npm run check
```
